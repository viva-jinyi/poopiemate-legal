# poopiemate-legal (archived)

POOPIEMATE’s policy pages used to be published from this repository at `viva-jinyi.github.io/poopiemate-legal/…`.

- **Source** of the privacy policy, terms, support page and open-source licenses: [`poopiemate/poopiemate-website`](https://github.com/poopiemate/poopiemate-website) → `src/legal/`, published at **[poopiemate.com/privacy/](https://poopiemate.com/privacy/)** (`/terms/`, `/support/`, `/licenses/`, English under `/en/`).
- **Legacy addresses** (`viva-jinyi.github.io/poopiemate-legal/privacy-ko` and friends, opened by app versions up to 2.0.0) are now served by [`viva-jinyi/viva-jinyi.github.io`](https://github.com/viva-jinyi/viva-jinyi.github.io).

From app 2.0.1 on, the app opens poopiemate.com directly.
